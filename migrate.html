🔄 Migration des IDs des participants

ℹ️ À propos de cette migration

Cette migration va mettre à jour les IDs des participants pour utiliser un format cohérent basé sur leur nom. Cela résoudra le problème des participants qui disparaissent de la page de consultation.

⚠️ Important
  • Cette migration doit être exécutée une seule fois
  • Elle modifiera les données dans localStorage
  • Assurez-vous d'avoir une sauvegarde si nécessaire
✅ Migration réussie!

Prochaines étapes:

  1. Rafraîchissez la page d'administration (index.html)
  2. Rafraîchissez la page de consultation (consulta.html)
  3. Vérifiez que tous les participants apparaissent correctement
