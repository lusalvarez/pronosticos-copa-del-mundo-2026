🧹 Nettoyer les données locales de Marta

ℹ️ Information:

Ce script va scanner et nettoyer toutes les données de "Marta" stockées dans le localStorage de votre navigateur.

Le localStorage est utilisé pour stocker temporairement les pronostics avant leur envoi à Firebase.

⚠️ Important:
  • Ouvrez cette page depuis le même domaine que votre application (même origine)
  • Les données supprimées du localStorage ne peuvent pas être récupérées
  • Cela n'affectera pas les données dans Firebase
