🧹 Nettoyer les Participants Supprimés

⚠️ Problème détecté :
Quand vous supprimez un participant dans l'écran admin, il est supprimé du localStorage mais ses données restent dans Firebase. C'est pourquoi il réapparaît dans la page de consultation et dans l'affichage des pronostics.

Solution : Ce script va lister tous les participants dans Firebase et vous permettre de les supprimer définitivement.
