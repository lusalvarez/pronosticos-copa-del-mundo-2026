📝 Charger des pronósticos pour un participant

Outil administrateur pour saisir les pronósticos d'un participant qui ne peut pas le faire lui-même

📋 Procédure :
  1. Entrez le nom et mot de passe du participant
  2. Cliquez sur "Créer le compte et charger les matchs"
  3. Saisissez les pronósticos pour chaque match
  4. Cliquez sur "Envoyer tous les pronósticos"
  5. Communiquez le nom et mot de passe au participant
