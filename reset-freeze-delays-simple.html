🔄 Supprimer les décalages de freeze

⚠️ Attention :
Cette opération va supprimer tous les décalages de freeze (+25h, +22h, +13h, etc.) dans Firebase. Les timestamps reviendront à -24h avant chaque match.

📋 Instructions

Suivez ces étapes pour supprimer les décalages :

1 Ouvrez la console du navigateur
Appuyez sur F12 puis cliquez sur l'onglet Console
2 Copiez et collez cette commande dans la console :
firebase.database().ref('freezeDelays').remove().then(() => console.log('✅ Décalages supprimés avec succès')).catch(err => console.error('❌ Erreur:', err));
3 Appuyez sur Entrée
Vous devriez voir le message "✅ Décalages supprimés avec succès"
4 Vérifiez que la suppression a fonctionné :
firebase.database().ref('freezeDelays').once('value').then(snap => console.log('Décalages restants:', snap.val()));
Résultat attendu : Décalages restants: null
5 Actualisez les pages
Actualisez participant.html et consulta.html avec Ctrl+Shift+R pour appliquer les changements.
💡 Alternative :
Si la commande ne fonctionne pas, vous pouvez aussi supprimer manuellement dans la console Firebase :
  1. Allez sur Firebase Console
  2. Naviguez vers Realtime Database
  3. Trouvez le nœud freezeDelays
  4. Cliquez sur les 3 points → Delete
